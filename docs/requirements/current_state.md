## 当前项目状态

当前项目是一个《人工智能原理》课程知识可视化 demo，采用 Vite + React + TypeScript 实现，为纯前端单页应用，使用 `react-router-dom`（HashRouter）做路由。项目不接入后端、数据库或外部图片资源，课程内容和展示结构主要写在 `src/data/courseKnowledge.ts` 中。

页面经 R003 重构为**三级递进导航**（HashRouter，URL 反映层级、刷新不丢位置、前进后退可用）：

- **Level 0 首页书架**（`/`）：标题「知识森林学习笔记」+ 4 张课程卡桌面端一字排开（单卡放大，窄屏自然回流为 2 列 / 1 列叠放）；仅「人工智能原理」可进入，其余三门为禁用占位态。整页内容垂直居中、首屏看得见全部 4 张卡，页面背景统一覆盖到底无白块。无 stat 计数器、无旧工作台 Header。
- **Level 1 章节导览**（`/ai`）：**沿途生长的徒步长卷 + 全展开 + 章节序列索引**——
  - **长卷主体**（R010 基线，R011 保留）：一条向心 Catmull-Rom（α=0.5）平滑曲线小径，按全课程顺序串起 **8 章地标 + 49 个小节共 57 个节点**，自上而下纵向滚动从「林口」走到「林深处」。版面由 `ResizeObserver` 测宽响应式重算；8 章 = 8 种扁平几何树种剪影（松/杨/圆冠/橡/塔柏/桦/柳/灌丛）+ 小路按章节分段染色；49 个小节 = 该章配色的小树苗，标题常驻；点小节 → 该点阅读页；点章节地标 → 该章首点；悬停/聚焦浮出**单张**轻预览卡。按小节进度（已长成 / 未长成 / 上次读到这里）。纤细 sticky 顶栏含返回书架 + 「已点亮 N/49」进度。R008 的章节预览大方框（`ChapterPreviewDialog`）已退役。
  - **全展开**（R011 新增）：长卷外层白色卡片框已拆除；视口背景用 `body:has(.forest-trail-page)` 与草地同色调（仅作用于 `/ai`，不泄漏到首页 / 阅读页）；绿色长卷铺满主区，与页面浑然一体。
  - **右侧章节序列索引**（R011 新增）：8 章 · 序号 + accent 色点 + 短标题；用 React Portal 挂到 `document.body` 以保证 `position: fixed` 在所有滚动位置稳定可见；scroll-spy 跟随高亮当前主视区章节，点击平滑滚动到该章地标（`prefers-reduced-motion` 退化为瞬时）；键盘可达，活动项带 `aria-current="location"`。
  - **可收起 ↔ 指南针**（R011 新增）：面板可收起为一个扁平几何指南针图标（与森林视觉一致），点指南针展开；状态用 `localStorage` 持久化；收起时 `sidebarReserved` 归零、`computeLayout` 重算让长卷在主视区居中；展开时为面板让位。桌面 ≥1024 启用；中屏 / 移动 <1024 直接隐藏，由顶栏「N/49」承担位置感知。
  - **R012 微调（6 次轮内迭代收敛）**：① **拉宽**——`contentMax` 1040→1200、`rowH` 300→328（元素尺寸不变）；② **标题翻边**——`useLayoutEffect` 中用 `getBoundingClientRect()` 实测包围盒，两 pass 算法让冲突标题翻 `above ↔ below`，地标固定不翻；相邻节点间小节标题两两实测 0 重叠；③ **路径有机扰动**——在向心 Catmull-Rom 之上加一层沿法向的扰动：全局弧长参数化 + 全局连续低频噪声 `noise(s) = sin(2π·s/λ₁ + φ₁) + 0.18·sin(2π·s/λ₂ + φ₂)` + C² 端点窗 `pinch(t_arc) = sin⁴(π·t_arc)`，振幅桌面 4 px / 移动 2.5 px、主波长桌面 1000 px / 移动 700 px、`λ₂ = λ₁ / 1.73` 保持无理数比；三层路面（band / dash / 章节分段染色）共用同一条扰动 path；节点处 pinch=0 → 49+8 个 anchor 精确落在路上（误差 ≤ 0.5 px）；切换索引展开收起 / `ResizeObserver` 重排后 path `d` 完全一致（确定性）。观感为"轻倚"型——曲线几乎像直线但有一丝缓慢倚向。
- **Level 2 知识点阅读**（`/ai/:chapterId/:pointId`）：复用 R002 阅读分层（引子 → 核心思想 → 图/动画 → 正文/内联公式 → 参考折叠 → 延伸）；进入章节默认落在首个知识点；右侧悬浮章节列表展示本章知识点（可切换、可收起、不遮挡正文，桌面端为预留栅格列 + sticky，移动端为正文上方收纳条），并含切换章节 / 返回书架入口；上一点/下一点按全课程连续序列推进，章末自动进入下一章首点。

当前数据规模：

- 8 个章节（数据层为知识簇 cluster）。
- 49 个结构化知识点。
- 多种自绘 SVG 图示类型。
- 4 类轻量动画示例：注意力流动、梯度下降、A* 搜索扩展、智能体闭环。

当前主要交互：

- 首页选择课程（仅 AI 原理可进入）。
- 在徒步长卷地图上滚动浏览整条小径；点任一小节树苗直达该点阅读页，点章节地标直达该章首点；悬停/聚焦显示单张轻预览卡；纤细顶栏可看到当前已点亮的进度与返回书架入口。
- 阅读页用悬浮章节列表切换本章知识点，或用上一点/下一点连续推进（可跨章）。
- 参考类次级内容（关键术语、对比、应用、前置知识）以折叠形式按需展开。
- 三级之间有统一的页面级淡入转场。
- 图示和动画作为知识解释内容展示，但用户对这些内容本身的交互仍较少。
