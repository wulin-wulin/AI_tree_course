## 森林导览页相机交互与视觉（R011 + R012 + R013）

`/ai` 为绕地面注视点的球面相机，状态 `{ theta(水平朝向), phi(俯仰), r(距离/缩放), target(注视点) }`：

- **R013 视觉基线**：天空由 `HORIZON_COLOR` / `ZENITH_COLOR` 渐变天空球承载，白云为轻量 sprite 云带；地面为跟随相机的大圆盘米色黄褐地面（`GROUND_COLOR = #e7e0cc`），不再露出方形地面边。白天半球光、环境光与投影方向光提供明亮户外感；树冠颜色在保留簇色相的前提下降饱和，远景不默认显示所有树标签，拉近或悬停时显示，减少标签糊脸。
- **右键拖动（或 Ctrl/Meta + 左键）= 转视角**：左右（dx）绕森林 360° 自由旋转水平朝向（不夹紧）；上下（dy）调俯仰，上滑更贴地平线并可继续抬头看到天空，下滑更俯视，俯仰交互范围为 `[0.62, 1.44]`（始终在地面之上、保留 3D 纵深，避免过度正俯视）。用 Pointer Events + `setPointerCapture`，右键拖动可靠不丢事件。
- **左键拖动 = 平移**：按当前朝向投影使方向跟手；target 经 `_clampTarget` 夹在「内容包围盒外扩 15%」的限位框内，森林拖不出视野、回得来。
- **滚轮 = 缩放**：r ∈ [250, 12000]。
- **`⟳` 重置 / 初始加载 = 最佳视角**：按内容包围盒质心定 target、FOV 反算 r（`_frameRadius`）框住整片森林、`theta=-π/2 / phi=1.0` 的自然 3/4 俯视；初始与重置共用同一组参数；重置复位 target/theta/phi/r 四量。
- **图例 / 下拉跳转知识簇 = `flyToCluster`**：左侧图例与顶部「跳到知识簇」下拉点击任一簇，按该簇全部知识点的包围盒框住其范围（23 簇都稳定生效，沿用当前俯仰/朝向）。

## 数据与构建

- 数据规模：**603 个知识点 / 23 个知识簇**（簇即学习者可见的「章节」）；16 种自绘 SVG 图示类型；4 类动画（注意力流动、梯度下降、A* 搜索扩展、智能体闭环）。
- 数据架构：`src/data/index.json`（轻量索引：簇 meta + 点 meta + 预算坐标/scale + 簇凸包多边形）+ `src/data/points/*.json`（603 个，全量详情，运行时按需 `import()` 懒加载，各自切为独立 chunk）。`src/data/clusters.json` 为 23 簇定义。
- `courseKnowledge.ts` 运行时**只提供类型定义**（组件均 `import type`），其手写知识点同时作为数据管线的输入源之一；运行时数据来源是 `index.json` + `points/*.json`，不是它。
- 数据管线：`scripts/build_knowledge.mjs` + `scripts/lib/*`（挖矿式转换参考项目知识点 + 归并 courseKnowledge 手写点 + 去重 + 解析前置引用 + 布局），可重跑产出 index.json 与 points/*.json。课程思政 `ideologicalElement` 已取消、管线不依赖 LLM。
- 导航：`src/data/courseNav.ts` 读 `index.json`，把 603 点按「簇顺序 + 簇内顺序」拉直成连续学习序列。
