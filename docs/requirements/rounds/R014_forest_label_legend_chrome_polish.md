# R014 - 森林页知识点标签、导览窗与白色 chrome 优化

状态：Implemented

创建日期：2026-06-25

## 背景

R013 将 `/ai` 森林页改造成明亮日间场景后，页面主体氛围变亮，但若干 UI 元素仍沿用深色森林时期的视觉处理。用户查看运行中的页面后指出：知识点名称标签当前看起来像“黑体白边”，字号偏小、视觉不舒服；左下角知识簇导览窗口需要更灵活；顶部栏与导览窗口也应改成与网站初始页一致的白色风格，减少深色玻璃与亮色场景之间的不协调。

本轮只处理 `/ai` 森林页的界面层视觉与左下导览窗口交互，不改数据、布局算法、阅读页、首页、相机交互与树/地面/天空场景本体。

## 用户真实反馈

逐字记录：

1. “关于知识点的名称文字显示，目前是黑体白边然后而且有点小，视觉上看着不舒服，知识簇的文子显示是可以的没啥问题，这个问题需要修正，执行智能体需要像一套方案优化一下知识点名称显示的具体方法”
2. “左下角的知识簇导览窗口优化一下，做成可以拖动和隐藏的”
3. “界面的上边框和刚刚提到的知识点导览框需要换成和网站初始也相一致的白色，这样颜色才能那个协调”

> 注：第 1 条里的“知识簇的文字显示”指簇标签可接受，本轮不要重做簇标签样式；重点是知识点名称标签（树标签）。

## 当前实现现状

- `src/forest/vendor/scene3d.js` 中树标签在 `_buildTrees()` 内创建，当前为 `font-size:9px`、深色文字 + 白色光晕/描边，默认远景隐藏，拉近或悬停显示。
- 知识簇标签在 `_buildLabels()` 内创建，当前彩色字 + 深色半透明 pill，用户认为可接受，本轮默认不改。
- `src/components/ForestMapPage.tsx` 中左下角导览为 `#forest-legend` 静态浮层，列出 23 个知识簇，点击可 `flyToCluster`。
- `src/styles.css` 中 `#forest-topbar` 与 `#forest-legend` 仍是深色半透明玻璃风格；当前亮色天空/米色地面下，用户希望它们改成与首页更一致的白色界面。

## 本轮目标

让 `/ai` 森林页在 R013 明亮日间场景上形成更协调、可用的界面层：

- 知识点名称标签不再像“黑体白边小字”，而是更舒适、清晰、克制。
- 左下知识簇导览窗口可以拖动，也可以隐藏/恢复。
- 顶部栏与知识簇导览窗口改为白色/浅色 UI，与网站初始页风格更一致。

## 具体需求

### 需求 1：优化知识点名称标签显示方案

- 执行智能体需要先基于当前 R013 亮色森林，设计并实现一套更舒服的**知识点名称标签**视觉方案，而不是只把字号机械调大。
- 必须修正用户指出的观感问题：
  - 当前标签看起来像“黑体白边”，应避免厚重黑字 + 生硬白描边的效果。
  - 当前字号偏小，近景/悬停时阅读吃力，应适度放大并提高可读性。
- 可选方向由执行智能体结合截图决定，但最终效果应满足：
  - 文字在米色地面、树冠、蓝天附近都清晰；
  - 不抢知识簇标签的层级，不在默认全景造成大面积文字糊脸；
  - 近景、簇跳转后、悬停单棵树时都读得舒服；
  - 视觉上更像精致 UI 标签，而不是粗糙描边字。
- 建议优先考虑这些方案组合：
  - 使用较深但柔和的文字色（如墨绿/深灰），降低纯黑压迫感；
  - 使用半透明浅色或暖白小底牌、轻阴影、细边框，而不是强白色外描边；
  - 字号提升到约 11–13px，并按标签状态区分：悬停/近景可更清晰，远景仍克制；
  - 控制最大宽度与截断策略，长名称不要撑破或遮挡过多树冠；
  - 通过 CSS class 管理标签样式，减少在 JS 字符串里堆过多样式（若改动成本合理）。
- 不要重做知识簇标签；除非为了整体协调做极小幅兼容调整，并在执行反馈说明。

### 需求 2：左下知识簇导览窗口可拖动、可隐藏

- 将左下角 `#forest-legend` 从固定静态窗口升级为可交互的知识簇导览面板。
- 面板需要支持拖动：
  - 拖动应有明确拖拽把手，建议放在面板标题栏区域；
  - 拖动时不要误触知识簇条目，点击知识簇仍应正常 `flyToCluster`；
  - 拖动位置应限制在视口内，避免拖出屏幕后找不回来；
  - 窗口尺寸变化或页面刷新后的持久化不是硬性要求；如做本地持久化也可以，但不要增加复杂度。
- 面板需要支持隐藏/恢复：
  - 面板上提供隐藏按钮；
  - 隐藏后页面上仍保留一个小型恢复入口（例如左下角“知识簇”按钮或图标按钮），用户能一键重新显示；
  - 隐藏状态不应影响顶部下拉跳转知识簇。
- 面板仍需保留现有 23 个知识簇列表、颜色 swatch、数量、点击跳转能力。
- 交互需要兼顾鼠标与键盘基础可达性：隐藏/恢复按钮可 Tab 聚焦并有可理解的 `aria-label` 或文本。

### 需求 3：顶部栏与知识簇导览窗口改为白色风格

- 将森林页顶部栏（`#forest-topbar`）从深色玻璃改为与网站初始页更一致的白色/浅色 UI。
- 将知识簇导览窗口同步改为白色/浅色 UI，与顶部栏形成同一套界面语言。
- 设计要求：
  - 使用白色或接近白色的面板背景，可带轻微透明度/模糊、细边框与柔和阴影；
  - 文字改为深色系，保证在白色 UI 上清晰；
  - 仍保留森林页的绿色/簇色作为适度强调，不要做成全深色；
  - 搜索框、搜索结果、知识簇下拉、重置按钮等顶部栏子控件需要同步适配浅色风格；
  - 白色 UI 压在亮色天空/地面上仍要有足够层次，不应发灰、发糊或像临时默认表单。
- 不要求把右侧知识点详情面板改成白色；本轮只明确要求顶部栏与左下知识簇导览窗口。若执行智能体认为搜索结果浮层也必须跟随顶部栏变浅，可一并处理并在反馈中说明。

## 非目标

- 不改知识点数据、簇数据、布局算法、`index.json` 或数据管线。
- 不改 R011/R012 的相机交互语义（右键旋转、左键平移、滚轮缩放、重置、簇跳转）。
- 不改 R013 的天空、地面、云、树形、阴影与簇区域曲线。
- 不重做知识簇 DOM 标签；用户已明确该处文字基本可接受。
- 不改首页、阅读页、右侧知识点详情面板，除非发现极小的样式冲突必须顺手修正。
- 不引入重型 UI 依赖；优先用现有 React 状态、CSS 与 Pointer Events 实现。

## 验收标准

- `npm run build` 通过。
- `/ai` 默认全景下顶部栏与左下知识簇导览窗口为协调的白色/浅色 UI，和首页气质更一致，文字清楚。
- 知识点名称标签在悬停、拉近、簇跳转近景下明显比当前“黑体白边小字”更舒服，字号、底牌/阴影、层级都合理；默认全景不出现大面积文字糊脸。
- 知识簇标签保持基本现状，不因本轮改动变差。
- 左下知识簇导览窗口可以拖动，拖动过程不误触簇跳转，且不会拖出屏幕找不到。
- 左下知识簇导览窗口可以隐藏，并能通过清晰的恢复入口重新显示；隐藏后顶部下拉跳转仍可用。
- 搜索框、下拉框、重置按钮、导览列表 hover/focus 状态在浅色风格下可读、可点、无明显错位。
- 无控制台错误；桌面视口下没有明显遮挡或重叠问题。
- 按 `AGENT_PROTOCOL.md` 截图自检：至少包含默认全景、悬停单个知识点标签、跳转某个知识簇后的近景标签、导览窗口拖动后、导览窗口隐藏/恢复状态。

## 执行备注

- 主要参考文件：
  - `src/forest/vendor/scene3d.js`：知识点名称标签创建与显示逻辑（`_buildTrees()`、`setHover()`、`_refreshVisibility()`、`_updateLabelPositions()` 等）。
  - `src/components/ForestMapPage.tsx`：顶部栏、搜索、下拉、重置按钮、左下知识簇导览窗口结构；导览窗口拖动/隐藏状态建议在这里实现。
  - `src/styles.css`：`#forest-topbar`、`.forest-search*`、`.forest-region-select`、`.forest-reset`、`#forest-legend`、`.forest-legend-*` 等样式。
- 执行时请保持改动范围小而完整：这是一轮 UI polish，不要借机重构森林渲染核心。
- 拖动导览窗口建议使用 Pointer Events，并在拖动期间 `preventDefault`/`setPointerCapture`；点击知识簇条目时不要启动拖动。
- 白色风格建议优先参考首页已有浅色卡片/导航的视觉语言，而不是浏览器默认控件样式。
- 本轮涉及界面/视觉，完成后必须截图自检并微调；不要只以 `npm run build` 通过作为达标。

## 执行反馈

### 实现概况

- 只处理 `/ai` 森林页 UI polish：知识点名称标签改为暖白小底牌 + 深灰绿文字 + 柔和阴影的 CSS class 方案；顶部栏、搜索、下拉、重置按钮和左下知识簇导览窗改为与首页一致的浅色面板风格；左下导览窗新增拖动、隐藏与恢复入口。
- 未改数据、布局算法、相机交互、阅读页、首页，也未改 R013 的天空/地面/云/树形/簇曲线场景本体。知识簇 DOM 标签保持原有深色 pill 风格，仅树标签和 chrome 发生本轮改动。

### 已完成需求

- **需求 1（知识点名称标签）**：`scene3d.js` 中树标签不再使用内联“深字 + 白光晕”样式，改为 `forest-tree-label` / `is-hovered` class。样式由 CSS 管理：12px 字号、暖白半透明底牌、细边框、柔和投影、最大宽度与省略号；悬停时轻微增强边框和阴影。远景仍默认不铺满树标签，悬停单棵树或拉近/簇跳转近景时显示，避免默认全景糊脸。
- **需求 2（导览窗拖动、隐藏/恢复）**：`ForestMapPage.tsx` 为左下知识簇导览窗加入标题栏拖动把手，使用 Pointer Events + `setPointerCapture`；拖动位置按视口边界夹紧，避免拖出屏幕。导览窗保留 23 个知识簇、颜色 swatch、数量与点击 `flyToCluster` 能力。新增“隐藏”按钮和隐藏后的“知识簇”恢复按钮，二者均可键盘聚焦并带 `aria-label`。
- **需求 3（浅色 chrome）**：`#forest-topbar`、搜索框、搜索结果、知识簇下拉、重置按钮、`#forest-legend`、导览列表 hover/focus、恢复按钮统一改为白色/暖白面板、深色文字、细边框、柔和阴影和绿色强调，压在 R013 明亮森林上更协调。
