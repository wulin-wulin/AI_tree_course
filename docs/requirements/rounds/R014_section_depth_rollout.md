# R014 - 教材级内容铺开到全部章节

状态：Implemented

创建日期：2026-06-07

确认日期：2026-06-07

## 背景

R013 把知识点阅读页加厚到「教材级」，并在试点章「搜索与问题求解」（7 点）验收通过：每页含通俗直觉、伪代码、多例题、复杂度表、对比表、常见误区、想深入（折叠）、自测、知识点关联，默认加载即内容充实、视觉单章一色。

R013 明确把「试点章之外 7 章」列为非目标，待样板验收后再铺开。现样板已被人类用户接受，本轮（R014）按 Split 承接：把同一套教材级内容结构铺开到**其余 7 章共 42 个知识点**。

## 用户真实反馈与想法

- 「感觉可以，将这个改动扩散到每个章节吧。」
- 执行方式经确认：**多智能体工作流并行**（按章分派）；轮次记为**新开 R014**。

## 已确认的关键决策

- **范围**：导论与历史、知识表示与推理、机器学习基础、神经网络与深度学习、自然语言处理与计算机视觉、强化学习与智能体、生成式 AI 与安全伦理——共 7 章 42 个知识点。
- **内容结构**：完全沿用 R013 教材级模板与字段（`intuition` / `deepDive` / `workedExamples` / `pseudocode` / `complexity` / `comparison` / `pitfalls` / `quiz` / `relatedPoints`）。
- **按点裁剪**：算法型点（含明确流程/公式）配伪代码+复杂度+对比；概念/伦理型点（如「AI 伦理」「可解释性」）可省略伪代码/复杂度，改以对比表、误区、案例承重。每点至少有：直觉、展开讲讲、1+ 例题或案例、2+ 自测、关联。
- **视觉**：不改 R013 已定样式；继续「单章一色」，换章随 accent 自动变色，误区 ✗/✓ 红绿语义色。
- **存储重构**：教材级内容抽到 `src/data/courseEnrichment.ts` 的 `Record<pointId, PointEnrichment>` 映射，在 `courseKnowledge.ts` 与基础数据合并；便于批量写入与维护（试点 7 点亦并入该映射，统一一处）。

## 本轮目标

让全部 8 章 49 个知识点的阅读页都达到 R013 的教材级厚度与视觉一致性；通读任意章节任意点都「读得下去、学得到」，不再单薄。

## 具体需求

- 新建 `src/data/courseEnrichment.ts`，导出 `enrichment: Record<string, PointEnrichment>`，包含全部 49 点（7 试点 + 42 新）的教材级内容。
- `courseKnowledge.ts` 将 `knowledgePoints` 改为基础数组与 `enrichment` 合并的结果（`{...base, ...enrichment[id]}`）；移除试点 7 点的内联加厚字段，统一到映射。
- 内容必须准确、符合《人工智能原理》课程口径；`relatedPoints` 只引用真实存在的知识点 id，优先同章「前置→本节→延伸」链条、可少量跨章。
- 渲染层（`KnowledgeDetailPanel` 顺序、`SectionDepthBlocks` 组件、样式）沿用 R013，不需重做。

## 非目标

- 不改三级导航结构与路由；不动首页书架、章节长卷。
- 不改 R013 已定的块顺序与视觉样式。
- 不新增知识点数量（仍 49 个）。
- 不引入后端、外部图片资源或新重型依赖。
