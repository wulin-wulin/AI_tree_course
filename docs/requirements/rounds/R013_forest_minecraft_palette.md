# R013 - 森林场景视觉改造：柔和簇边缘 + 明亮日间（我的世界）色调

状态：Accepted（已结束；明亮日间森林场景作为当前视觉基线）

创建日期：2026-06-23

## 背景

森林导览页（`/ai`）经 R010–R012 已是深色倾斜 3D 树森林。用户体验后认为：① 知识簇的边缘线是生硬折线，想要柔和曲线；② 整体色调太阴沉，想参照《我的世界》(Minecraft) 的**明亮日间色调**改造——黄褐含绿草地 + 蓝天白云 + 天际线。本轮只聚焦 `/ai` 森林的**场景观感**，不动数据、布局、相机交互（R011/R012 已验收）、阅读页与首页。

> 这是设计驱动的一轮，第 2 条需要认真设计与反复截图调试。

## 用户真实反馈

逐字记录：

1. 「将每个知识簇的边缘线改成柔和一点的曲线，现在的折线太生硬了。」
2. 「现在的界面整体色调太阴沉，我们需要加以改造：参照我的世界的色调，将地面改成黄褐色绿草地的形式，加上蓝天白云、天际线，这一部分可能要需要好好设计一下。」

### 已确认的设计方向（讨论窗口与用户对齐）

- **美术方向 = 亮色调氛围**：只借《我的世界》的明亮白天调色（黄褐含绿草地 + 蓝天白云 + 地平线），**保留现有平滑低多边形树与形状**，**不做像素/体素方块质感**（不贴方块纹理、不重做树）。理由：轻量、连贯、性能好。
- **页面 chrome = 保留深色玻璃**：顶栏 / 图例 / 搜索 / 下拉等保持现有深色半透明玻璃风格（压在亮场景上对比清晰、可读性好）；本轮只需**重调簇标签 / 树标签颜色**，使其在变亮的背景上仍清晰可读。
- **保留簇配色编码**：树与簇区域仍按簇 accent 着色（功能性区分），只需保证在亮地面 / 亮天空上对比足够、不刺眼。

## 当前实现现状（执行前必读，已从代码确认）

`src/forest/vendor/scene3d.js`：

- 背景（当前"天空"）：构造函数 `this.renderer.setClearColor(0x0f0f23)`（深蓝黑，行 20）；`alpha:false`。
- 灯光（为暗场景调，行 32-36）：`AmbientLight(0x404060, 0.5)`（冷暗环境光）+ `DirectionalLight(0xfff8e8, 2.0)` 暖阳 + `DirectionalLight(0x8899cc, 0.5)` 冷补光。
- 世界坐标 **Z 朝上**（`camera.up=(0,0,1)`，行 28）；地面在 z=0 的 XY 平面，天空在 +Z 与远处地平线方向。R012 把默认俯仰放平到 `phi=1.18`，**地平线会明显露出**。
- 地面 `_buildGround()`（行 74）：一块 `CANVAS_W×CANVAS_H = 4000×3000` 的 `PlaneGeometry`，`MeshBasicMaterial` 颜色 `0x1a1a2e`（深色、且 Basic 材质**不吃光照**），位于 z=-0.5。
- 簇区域 `_buildDomains()`（行 83）：遍历 `layout.domains`，每簇 `polygon`（凸包顶点）→ `Shape`→`ShapeGeometry` 填充（簇色，`opacity 0.12`）+ `EdgesGeometry`→`LineSegments`（簇色，`opacity 0.35`）。**边缘就是顶点直连的直线段 → 折线生硬。**
- 簇标签 `_buildLabels()`（行 99）：DOM 浮层，彩色字（簇色）+ `text-shadow:0 0 12px rgba(0,0,0,0.6)`（深阴影，专为暗背景）。
- 树标签（`_buildTrees` 内）：DOM 浮层，颜色 `#bbb` 灰 + 深色阴影。

`src/styles.css`（行 3724 起）：`.forest-parity-page` 背景 `#0f0f23`（在 canvas 之下，被不透明 canvas 覆盖）；topbar / legend / search / select 均深色玻璃 + 浅字，强调色 `#7EC8A4`。

## 本轮目标

让 `/ai` 森林从阴沉变成明亮、舒服的日间森林：簇边缘柔和成曲线；地面成黄褐含绿草地、天空成蓝天白云带地平线；同时保持簇配色编码与标签可读性，chrome 仍为深色玻璃。

## 具体需求

### 需求 1：知识簇边缘线改为柔和曲线

- 把 `_buildDomains()` 里每簇的**直线段轮廓**换成**柔和闭合曲线**：对 `polygon` 顶点做平滑（建议闭合 Catmull-Rom 样条，重采样成多点后连成平滑线），让簇边界看起来圆润、不再是折线。
  - 项目此前在 2D 地图小径用过 Catmull-Rom 平滑，技术上熟路，可参考。
- 填充形状（`ShapeGeometry`）建议也用**同一条平滑后的轮廓**重建，使填充边界与曲线描边吻合、不露出尖角。
- 保留每簇的 accent 配色与现有半透明层次（填充淡、描边略明显）；只改"形状的柔和度"，不改配色逻辑。
- 注意闭合处（首尾相接）要平滑过渡、不留断点或尖刺。

### 需求 2：明亮日间（我的世界）色调改造

按已确认的"亮色调氛围、非体素"方向，把整片 3D 场景从阴沉改成明亮白天森林。包含以下几块，需作为一个**协调的整体**设计（执行者反复截图调试到好看为止）：

- **天空（蓝天白云 + 天际线）**：
  - 把当前深色 `clearColor` 换成**蓝天**：建议天顶较深蓝 → 接近地平线渐浅的渐变（可用 skydome/大天空球、渐变背景贴图，或 three 的 Sky 等方案，执行者择优，避免引入重依赖；优先用现有 three 能力）。
  - 加**白云**：天空中可见柔和白云（billboard 精灵 / 云带贴图 / 简单柔白云块均可），数量与密度以"点缀、不喧宾夺主"为度。
  - 形成**天际线 / 地平线**：因相机已放平，地面远端会与天空相接，需把"地面边缘→天空"的衔接设计成自然地平线（建议用 `THREE.Fog` 把远处地面 / 树雾化融入天空色，或用足够大的地面 / 天空球避免硬边），避免露出 4000×3000 地面平面的生硬直边。
- **地面（黄褐含绿草地）**：
  - 把 `_buildGround()` 的深色平面改成**明亮草地**：以青草绿为主、带黄褐土地色调（《我的世界》白天草地 / 泥土那种明快感）。可用纯色 / 轻微色彩变化 / 柔和分块，但**不要方块像素贴图**（非体素方向）。
  - 材质改为能吃光照（如 `MeshLambertMaterial` / `MeshStandardMaterial`）或直接选明亮颜色，使地面在日光下显得明快、有起伏光感（执行者判断）。
- **灯光调成白天**：把为暗场景调的冷暗环境光 / 灯光改成**明亮日间**（提高环境光亮度、暖白阳光），让草地与树冠看起来被阳光照亮、整体明快，不发灰发暗。
- **标签可读性（亮背景适配）**：
  - 簇标签（`_buildLabels`，当前彩色字 + 深色外阴影）与树标签（`#bbb` 灰）在变亮的天空 / 草地上会糊。需重调：例如给文字加**浅色描边 / 白色光晕 / 半透明深色小底牌**，或改深色字配亮场景，确保在蓝天与草地上都清晰可读。
- **保留项**：树仍按簇 accent 着色（功能编码）——在亮地面上注意对比、别刺眼或与草地撞色到看不清；chrome（顶栏 / 图例 / 搜索 / 下拉）**保持深色玻璃**不变（仅在亮场景上自然形成对比即可，必要时微调透明度 / 阴影以保证可读）。

## 非目标

- 不做像素 / 体素方块质感（不贴 Minecraft 方块纹理、不把树 / 地面改成立方体）。
- 不改森林布局算法、`index.json` 数据、簇凸包 polygon 的生成（只改其**渲染呈现**）。
- 不改 R011 右键转视角 / 左键平移限位 / 缩放、R012 簇跳转 / 默认视角等已验收交互（如灯光 / 雾化影响观感可微调参数，但不改交互逻辑）。
- 不把 chrome 改成浅色 / 白天风（已确认保留深色玻璃）。
- 不改阅读页、首页。
- 不引入重型第三方资源 / 大体积贴图依赖；优先用现有 three 能力与轻量程序化方案，注意 600+ 树下的性能（首屏不明显卡顿）。

## 执行反馈

> 由执行智能体完成后填写。

### 实现概况

只改 `/ai` 森林场景观感:`scene3d.js` 把阴沉深色场景换成明亮日间(蓝天渐变天空球 + 跟随相机的地平线白云 + 雾化天际线 + 黄褐含绿草地 + 白天灯光),簇边缘由折线改为 Catmull-Rom 平滑曲线,簇/树标签重调为亮背景可读;`styles.css` 页面背景兜底改天空浅蓝。未碰数据/布局/簇 polygon 生成/相机交互(R011/R012)/阅读页/首页;chrome(顶栏/图例/搜索/下拉)保持深色玻璃;树与簇仍按 accent 配色。

### 已完成需求

- **需求 1（簇边缘柔和曲线）**:新增 `_smoothPolygon()`——对每簇凸包顶点做**闭合 Catmull-Rom 样条**(重采样 72 点);`_buildDomains()` 用同一条平滑轮廓重建填充(`ShapeGeometry`)与描边(`LineLoop`,替代原 `EdgesGeometry` 直线段),边界圆润、填充与描边吻合、闭合处无尖刺。保留 accent 配色与半透明层次(填充 0.16 / 描边 0.55,亮地面上略增强)。
- **需求 2（明亮日间色调）**:
  - **天空**:新增 `_buildSky()`——大天空球(R=15000,`BackSide`)+ 自写渐变 shader,按世界 Z 仰角天顶蓝 `#3f8fdb`→地平线浅蓝 `#bfe1f2`;`render()` 里天空球**跟随相机**永不裁剪。
  - **白云**:新增 `_buildClouds()`+`_makeCloudTexture()`——canvas 多团柔和白斑做蓬松云贴图,20 个 Sprite **挂在跟随相机的地平线环上**(固定方位角 + 低仰角 1°~8° + 远距离 9000~12500),保证相机始终看向地面注视点时云稳定出现在地平线上方天空带、任意朝向都有;`render()` 里缓慢绕方位角飘动。
  - **天际线**:(初版用 `scene.fog` 雾化)→ **按用户追加反馈去掉雾**,改为「**跟随相机的大圆盘地面(半径 18000)** + 天空球」自然形成干净的开放世界圆形天际线:地面每帧跟随相机 xy,永远向四周延伸到地平线、不露边,色彩也不再被雾洗成灰白。
  - **仰望天空(用户追加反馈)**:把俯仰上限 `phi` 提到 `PHI_MAX=1.50`(接近 π/2,相机仍在地面之上),并在 `_updateCamera` 让视线随 phi 连续抬升——`phi≤1.0` 俯视森林、过渡到地平线、`phi→1.50` 时通过抬高 `lookAt` 的 Z **抬头仰望天空**(约 +28°),右键上拖即可一路拖到满屏蓝天白云。
  - **地面**:`_buildGround()` 改 `MeshLambertMaterial`(吃光照);**配色按用户追加反馈从绿色改为米色 `#e7e0cc`(用户提供色板)**;形状从方形平面改为**圆盘 `CircleGeometry(16000)`**——无直边/直角,远端从任意方向均匀雾化,形成连续的开放世界式圆形天际线(修掉用户反馈的「方块/方形地面边」问题),`fog` 放宽到 `3500~15000`(< 地面半径,边缘永不露出)、过渡更柔和。
  - **白天灯光**:`HemisphereLight(天蓝/草绿,0.9)` + 暖白阳光 `DirectionalLight(1.2)` + 环境光 0.32,整体明快不发灰。
  - **标签可读性**:簇标签改为簇色字 + 深色半透明小底牌(`rgba(17,28,42,0.62)` 圆角 pill),保留配色又清晰;树标签由灰 `#bbb` 改深绿字 `#16321f` + 白色光晕,压在草地/天空都清晰。
  - **保留**:树/簇 accent 配色不变;chrome 深色玻璃不变。

### 未完成或部分完成

- 云在**默认平视角**下因可见天空带很薄(相机始终看向地面注视点,地平线偏屏幕上方)显得较淡;**俯仰拉低(看更多天空)时清晰可见**,符合「点缀、不喧宾夺主」。
- 云采用「跟随相机地平线环」而非世界固定位置(几何上保证可见),因此无近大远小视差——对远景云可接受。

### 执行中发现的问题

- 相机模型决定「天空只是地平线上方一条带」:世界放置的云极难落进该带,故改为跟随相机的地平线环 + 低仰角才稳定可见。
- 近地平线天空过白时白云没对比 → 把地平线色从近白 `#d6ecf7` 调蓝到 `#bfe1f2`,云才显现(地平线色同时是雾色/clearColor,保持一致避免天际线接缝)。
- `ShapeGeometry` 的描边若用 `EdgesGeometry` 会把平滑曲线又拆成可见折段;改用平滑点列直接建 `LineLoop` 才真正柔和。
