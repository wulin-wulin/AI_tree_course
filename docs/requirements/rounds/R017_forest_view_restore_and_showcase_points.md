# R017 - 森林视图返回恢复 + 录屏展示级知识点打磨

状态：Implemented

创建日期：2026-07-10

## 背景

R016 已完成阅读页富文本/公式渲染与领域学习路径第一版，但在真实使用链路中还有两个面向演示体验的关键问题：

1. 用户在森林导览页调整好视角、缩放和位置后，点击某个知识点进入阅读页；再从阅读页点击“切换章节”回到森林导览时，当前会重新回到默认视角。这会打断用户刚才的空间上下文。用户期望回到进入知识点前的森林视图位置。
2. 准备给客户录视频展示时，不能只依赖 603 个知识点的平均质量。需要精选几个最适合演示的知识点，针对内容和展示方式做“样板级”重构：图文并茂、公式美观、动画尽量丰富，能在录屏中展示项目的上限。

本轮聚焦“返回体验连续性”和“演示样板知识点”两件事。

## 用户真实反馈

逐字记录：

1. “当点进去一个知识点之后用户点击切换章节回到章节导览界面的时候，应该记忆之前进去知识点视图前的视图位置将他恢复而不是每次都回到默认视角 你应该能明白这个需求是说什么”
2. “挑选几个知识点 将里面的内容还有展示方式进行精心优化重构 这是为了想客户录视频展示 所以要挑选并针对几个知识点做精心美观优化  图文并茂 最好有动画 公式也要渲染美观”

## 当前实现现状

- 森林页：`src/components/ForestMapPage.tsx` 使用 `Scene3D` 渲染 `/ai`，点击树、搜索结果或学习路径列表可进入知识点阅读页。
- 阅读页：`src/components/ReadingPage.tsx` 右侧 dock 底部有“切换章节”按钮，当前会 `navigate('/ai')` 回到森林导览页。
- R015 已实现相机高度滑块，`Scene3D` 内已有相机状态 `{ theta, phi, r, target }` 及 `getCameraHeight` / `setCameraHeight` 等能力。
- R016 已实现 `RichText`、KaTeX 公式渲染、领域学习路径、森林虚线路径和阅读页路径模式，但 R016 当前仍为 `Implemented`，尚未在需求窗口完成审核。
- 数据源：完整知识点在 `src/data/points/*.json`。执行者可以针对少量精选点局部改内容，也可以新增少量展示型组件/样式；不要大规模重写 603 个点。

## 本轮目标

1. 用户从森林导览页进入知识点阅读页，再返回森林导览页时，应恢复进入阅读前的视图位置，而不是回默认视角。
2. 精选若干知识点做“客户录屏展示级”内容与呈现优化，形成几个足够漂亮、足够完整的示范页面。

## 具体需求

### 需求 1：从阅读页返回森林时恢复进入前视图

当用户从 `/ai` 森林导览页进入某个知识点阅读页，再在阅读页点击“切换章节”返回 `/ai` 时，应恢复进入阅读页前的森林视图状态。

必须恢复的视图状态：

- 相机水平朝向 `theta`。
- 相机俯仰/高度 `phi` 或对应的“视角高度”滑块值。
- 缩放距离 `r`。
- 地面注视点 `target.x / target.y`。
- 如果当前有领域学习路径高亮/虚线路径，返回后不应因为恢复视图而丢失路径状态。

交互要求：

- 从森林页点击树进入阅读页后，再点阅读页的“切换章节”，回到森林页应看到原来那片区域、原来的缩放与视角高度。
- 从森林页搜索结果进入阅读页、从学习路径列表进入阅读页，也应尽量保存并恢复进入前视图。
- 浏览器后退回到森林页时，如果技术上走同一路由恢复机制，也应尽量恢复；若不能完全覆盖，执行反馈要说明边界。
- 点击森林页的 `⟳` 重置按钮仍应回到默认最佳视角，并应清理或覆盖旧的待恢复视图，避免之后又突然恢复旧位置。
- 直接打开 `/ai`、刷新页面、或没有保存过森林视图时，应使用默认最佳视角，不要恢复一个过期/无效视图。
- 恢复视图不需要恢复 hover 状态、临时 tooltip、搜索框输入或知识簇导览窗位置；这些不是本轮重点。

实现建议：

- 在 `Scene3D` 中暴露视图状态读写方法，例如 `getViewState()` / `restoreViewState(state)`，命名按现有风格决定。
- 在从森林页进入阅读页前保存视图状态，可使用 `sessionStorage` 或路由 state；优先保证“阅读页点击切换章节返回”这一主链路稳定。
- 在阅读页的“切换章节”按钮返回 `/ai` 时带上恢复意图，避免用户直接访问 `/ai` 时误恢复过期视图。
- 恢复后要同步右上“视角高度”滑块值。

### 需求 2：精选 4-6 个录屏展示知识点

执行者需要从项目现有知识点中挑选 4-6 个适合客户录屏展示的知识点，并对它们做精心内容与展示优化。

选择标准：

- 主题要有代表性，覆盖不同 AI 方向，适合在短视频/客户演示中讲出亮点。
- 页面应能展示项目优势：富文本、公式、图示、动画、路径/森林跳转后的阅读体验。
- 优先选择已有 `visualType` / `animationType` 或具备公式/图示潜力的点。
- 不要只选全是同一类深度学习模型；应有算法、模型、搜索/规划、强化学习或生成式 AI 的多样性。

推荐候选（执行者可基于实际效果微调，但最终需在反馈中列出入选 ID）：

- `attention-mechanism`（注意力机制）：已有 attention 图示/动画，有公式，适合展示动态注意力。
- `transformer`（Transformer）：现代 AI 核心概念，已有 transformer 图示和 attention 动画潜力。
- `gradient-descent`（梯度下降）：已有 gradient 图示/动画和公式，适合展示优化过程。
- `a-star-search`（A* 搜索）：已有 search 图示/动画和公式，适合展示路径搜索。
- `q-learning` 或 `reinforcement-learning`：已有 agentLoop 动画，适合展示智能体交互。
- `diffusion-model` 或 `large-language-model`：适合生成式 AI/大模型客户演示，可补强图文结构。
- `cnn`（卷积神经网络）：视觉方向代表点，可补强图示和图文说明。

### 需求 3：精选知识点内容重构

对入选知识点进行“样板级”内容重构，而不是只换颜色或只补几句文字。

每个入选知识点至少应优化：

- **标题区与摘要**：摘要更适合口播和客户演示，能快速说明“这个点为什么重要”。
- **核心思想**：结构清晰，避免大段堆文字；必要时拆成短段、小标题或重点句。
- **基本原理**：按“直觉 → 步骤 → 公式 → 例子”组织，读者看得懂，录屏时讲得顺。
- **公式**：用 R016 的公式渲染能力呈现得美观；长公式要拆分或块级展示，不能横向撑破或难读。
- **图示**：尽量使用现有 `DiagramBlock` 能力或新增少量专属图示，让页面图文并茂。
- **动画**：能接入现有动画的点应接入或打磨动画；没有动画但非常适合展示的点，可以新增轻量动画组件，但不要过度工程化。
- **应用例子**：补一个贴近真实场景的短例子，适合客户理解。
- **关键术语 / 对比 / 前置知识**：整理得更有层次，避免全是松散词条。

允许的实现方式：

- 局部修改对应 `src/data/points/*.json` 内容。
- 在 `DiagramBlock` / `AnimationBlock` 中为少量精选点新增更精致的图示或动画分支。
- 新增轻量展示组件或样式 class，但要保持阅读页整体风格统一。
- 如需要标记“演示精选”知识点，可在前端用 ID 白名单实现，不必改数据 schema；若改 schema，应同步类型并说明原因。

不允许：

- 不要大规模改写所有 603 个知识点。
- 不要引入远程图片、视频或 CDN。
- 不要为了演示效果破坏普通知识点阅读体验。
- 不要把阅读页改成营销页；它仍然应是学习界面，只是这些点更精致。

### 需求 4：录屏展示路径与验证

执行者完成后，需要给出一条建议录屏检查路径，方便需求窗口或人类用户验收：

- 从森林页定位到某个精选知识点。
- 进入阅读页展示其标题、图示/动画、公式、核心解释。
- 切换到下一两个精选知识点，展示不同内容形态。
- 从阅读页点击“切换章节”回森林页，确认恢复进入前视图。

## 非目标

- 不接后端、数据库、账号系统或外部 LLM。
- 不重做 R016 的领域学习路径功能。
- 不重做森林布局、树形、天空、地面、云或簇区域曲线。
- 不重写 603 个知识点，只打磨少量精选点。
- 不要求移动端录屏级适配；桌面录屏视口优先。
- 不要求每个精选点都新增全新动画；已有动画可打磨复用，确实适合新增时再新增。

## 验收标准

- `npm run build` 通过。
- 从森林页任意调整视角/缩放/位置后进入知识点，再从阅读页点击“切换章节”返回，森林视图恢复到进入前状态。
- 返回恢复后右上“视角高度”滑块与实际相机状态一致。
- 使用搜索进入知识点、学习路径进入知识点后返回森林，视图恢复机制不破坏原功能；如有边界需在反馈中说明。
- 点击 `⟳` 重置后不会被旧保存视图再次覆盖。
- 至少 4 个精选知识点达到录屏展示级：内容结构清晰，图文并茂，公式美观，至少若干点带动画或动态图示。
- 执行反馈列出最终精选知识点 ID、每个点做了哪些内容/展示优化、是否有动画/公式/图示。
- 原有普通知识点阅读不回退；R016 的富文本/公式渲染、学习路径和森林虚线路径不被破坏。
- 按协议截图自检：森林进入前视图、阅读页返回后恢复视图、每个精选知识点阅读页、至少一个动画/公式特写。

### 实现概况

- 已完成森林视图返回恢复：从 `/ai` 进入阅读页前保存 `theta / phi / r / target.x / target.y`，阅读页“切换章节”返回或浏览器后退回到森林页时按保存 key 恢复视角，并同步右上“视角高度”滑块。
- 新增 `sessionStorage + history state` 的恢复意图机制：只有带匹配恢复 key 的返回才恢复，直接打开 `/ai` 不会消费旧视图；恢复成功后会消费保存状态，森林页“重置视图”会清理待恢复状态。
- 精选并打磨 6 个录屏展示知识点：`attention-mechanism`、`transformer`、`gradient-descent`、`a-star-search`、`q-learning`、`diffusion-model`。6 个点均补强摘要、核心思想、步骤化原理、KaTeX 公式、应用、对比、直觉解释、误区、优缺点和自测问答；其中 5 个点接入现有动画，`diffusion-model` 使用现有扩散图示和公式展示。

### 已完成需求

- 从森林页树点击、搜索结果、学习路径“开始学习/阅读”进入阅读页前保存当前相机视图。
- 阅读页 dock 底部“切换章节”和学习路径“返回森林路径”返回 `/ai` 时恢复进入阅读前的森林视图；浏览器后退链路也通过标记原森林历史记录实现恢复。
- 森林页重置按钮会清理旧的待恢复视图并回到默认最佳视角。
- 学习路径状态继续由原 `learningPath` 存储维护，视图恢复不会清空路径虚线、高亮和路径标签。
- 6 个精选知识点均达到图文并茂、公式渲染、结构化讲解的录屏展示目标。

### 未完成或部分完成

- 无阻断项。
- `diffusion-model` 未新增专属动画类型，原因是当前动画组件只支持 attention / gradient / search / agentLoop；本轮按“尽量有动画”的边界处理为静态扩散图示 + 美观公式，其余 5 个精选点均有动画。

### 执行中发现的问题

- 原知识点 JSON 同时承载阅读内容和森林布局元数据，重构内容时必须保留 `importance / pos / scale`，否则会影响数据校验和森林布局相关流程；本轮已全部补回并对齐 `index.json`。
- React StrictMode 下场景 effect 会双挂载，因此恢复状态不能在第一次 effect 立即消费；实现中延迟消费恢复 key，避免开发环境第二次挂载丢失恢复视图。

### 认为需求不合理或需要澄清的点

- 暂无。浏览器后退恢复已覆盖；直接打开 `/ai` 默认不恢复旧视图。
